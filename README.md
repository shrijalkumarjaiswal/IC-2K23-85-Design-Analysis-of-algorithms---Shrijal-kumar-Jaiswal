## Getting Started

Each unit folder contains individual program folders with:
- Python source code
- Where provided, a `README.md` with the problem statement, algorithm, pseudocode, complexity analysis, sample I/O, and learning outcomes
- Performance analysis scripts (where applicable)
- Experimental results and graphs

## How to Run

```bash
# Navigate to any program directory
cd Unit01-Introduction-Algorithms/Searching

# Run the Python implementation
python binary_search.py
```

For performance analysis experiments:

2. Results are stored in CSV format
3. Graphs are generated using matplotlib
4. Theoretical vs empirical complexity comparison is documented
